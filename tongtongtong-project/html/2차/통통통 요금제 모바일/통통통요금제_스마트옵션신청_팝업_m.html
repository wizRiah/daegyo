청구서 자동 생성
옵션이 신청됩니다.

  • 청구서 자동 생성 옵션은 신청당월 무료 입니다. (2025년 12월 청구)
  • 옵션 신청 버튼 클릭 시 청구서 자동 생성 기능은 심사 후 적용됩니다.
기능 안내
  • 수강료 청구서의 수동발행 번거로움과 실수를 줄이고 청구일자를 놓치지 않습니다.
  • 수강료 청구서 생성부터 학부모 안내까지 한번에 해결합니다.

반별 출결
옵션이 신청됩니다.

  • 반별 출결 옵션은 신청당월은 무료 입니다. (2025년 12월 청구)
  • 옵션신청 버튼 클릭 시 반별 출결 기능은 심사 후 적용됩니다.
기능 안내
  • 하루에 2회 수업을 듣는 학생의 반별 출석을 확인할 수 있는 기능입니다.
  • 반별 출결을 사용하지 않으면, 2회 수업에 대해 동일한 등원시간 / 하원시간이 적용됩니다.
  • 반의 시간표를 관리하시면, 출석 및 종료 시간에 따라 자동으로 출석, 지각이 표기됩니다.

수강료 분납
옵션이 신청됩니다.

  • 반별 출결 옵션은 신청당월은 무료 입니다. (2025년 12월 청구)
  • 옵션신청 버튼 클릭 시 반별 출결 기능은 심사 후 적용됩니다.
기능 안내
  • 수강료 납부 시, 수강료를 나눠서 일부만 납부받을 수 있는 기능입니다.
  • 수강료 분납 기능은 키오스크에서도 가능합니다.
  • 분납기능이 없으면, 원 청구서 전액을 수납해야 납부완료가 됩니다.

기능 안내

추천

청구서 자동생성과 함께 사용시 잔여회차가 모두 소진되면, 청구서가 발행됩니다.

  • 비대면 간편결제(후불) 은 사용량 만큼만 과금됩니다. (2025년 12월 청구)
  • 옵션신청 버튼 클릭 시 비대면 간편결제(후불) 기능은 심사 후 적용됩니다.
기능 안내
  • 학부모님의 학원방문 없이, 모바일 앱 설치 필요없이 간편하게 결제할 수 있는 기능입니다.
  • 도달률이 높은 카카오톡 / 문자메시지로 결제링크가 전송되어 수납률이 증가합니다.
  • 카드 단말기 수수료 수준으로 제공됩니다.

기능 안내

  • 카드 영수증, 교습비 원부 (교육청 기준 충족)등 영수증을 단말기에 즉시 출력할 수 있습니다.
